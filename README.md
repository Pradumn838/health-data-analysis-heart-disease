
 # 🫀 Health Data Analysis – Heart Disease Prediction

## 📌 Project Overview
This project focuses on analyzing healthcare and demographic data to identify key factors contributing to heart disease. The goal is to derive meaningful insights using data analysis techniques that can support data-driven healthcare decisions.

---

## 🎯 Objectives
- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Identify correlations between health attributes and heart disease
- Extract key insights from patient data

---

## 🛠️ Tools & Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Jupyter Notebook

---

## 📊 Dataset Description
The dataset contains patient health and demographic information such as:
- Age
- Gender
- Cholesterol levels
- Blood pressure
- Other medical indicators

---

## 🔄 Project Workflow
1. Data Collection  
2. Data Cleaning & Preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Correlation Analysis  
5. Insight Generation  

---

## 📈 Key Insights
- Identified major risk factors influencing heart disease  
- Observed strong relationships between age, cholesterol, and health conditions  
- Highlighted patterns useful for predictive analysis  

---

## 🚀 Outcome
- Cleaned and structured dataset ready for further analysis  
- Generated actionable insights to support healthcare decisions
